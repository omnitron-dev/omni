# Offline PDF fonts

Unmodified New Computer Modern text/math fonts and DejaVu Sans Mono from the
immutable Typst assets revision in `manifest.json`. They provide Latin, Cyrillic,
Greek and mathematical glyphs without system-font discovery or network access.
Additional scripts require explicitly supplied font bytes in the PDF API.

The source revision and SHA-256 of every font are recorded in the manifest.
The original GUST/LPPL and Bitstream/Arev notices accompany these files. These
font licenses are separate from the package's source-code license.
